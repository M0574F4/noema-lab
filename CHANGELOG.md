# Changelog

All notable changes to Noema will be documented here.

The project uses semantic versions for software releases and explicit benchmark IDs/versions for
benchmark protocol compatibility.

## 0.2.0 - Unreleased

The working package remains `0.2.0.dev0`. A stable version and tag will be created only after its
exact release archives pass the public test and packaging workflows.

### Fixed

- Release-hardening changes are tracked here until an immutable tagged release is built and tested.
- A self-contained generated launch-evidence projection now supplies one provenance-bound source
  for README, documentation, webpage, figure, table, and video-overlay numbers while preserving its
  experimental warning independently of release clearance.
- A flagship “Break the comparison” evidence lab now turns that projection into an interactive
  contract audit with four reproducible failure modes and a real-browser release probe.
- A deterministic launch-asset generator now renders the complete F0–F5 visual system and T0–T2
  table set from the canonical launch evidence, with digest closure and experimental guardrails.
- The existing Pages root, documentation tree, and README now share one demo-first information
  architecture, reusing the maintained tutorials, demonstrations, evidence, and reference pages
  instead of creating parallel website or getting-started content.
- Version, package, evidence-verification, filesystem-containment, resource-isolation, provenance,
  accessibility, and benchmark-status checks are part of the pre-release validation process.

## 0.1.0 - Development snapshot (not released)

### Added

- Typed DAG/recipe execution for data, sender, receiver, channel, metrics, and artifacts.
- Benchmark packs and reproducible run/result bundles.
- Strict recipe lint checks for canonical bit and symbol transport contracts.
- External adapter SDK for image codec and semantic model wrappers.
- Dashboard for configuring recipes, inspecting graphs, launching runs, and comparing results.
- Initial image, text, VQA, retrieval, detection/segmentation, wireless, and generative receiver
  task contracts.

### Snapshot Notes

- Public-release metadata, governance, contribution, security, and citation files were added while
  preparing the repository as a research software artifact. No immutable `v0.1.0` software release
  was created from this snapshot.
