OFDM resource-allocation result snapshot
========================================

current_results_all_metrics.csv is the unchanged Results > Export all metrics file captured on
2026-07-22. Its SHA-256 is:

  e37f400827d9bc2a53b50e3090a1f2dfd3c99cdc5834b9947ee5f666bd008611

The snapshot contains 15 ordinary UI runs: equal power, the learned allocator, and water filling at
five average transmit-power budgets. All runs use the template's default payload/channel seed family
(23, 23001, and 23002). It is therefore an illustrative smoke-run snapshot, not the final paired
held-out benchmark evidence produced by build_benchmark.py.

summary_table.csv, spectral_efficiency_table.csv, and the SVG files under
docs/demo/assets/ofdm_resource_allocation/ are deterministic projections generated by
tools/generate_ofdm_resource_allocation_demo_assets.py. Keep the raw CSV when changing those
projections so every displayed number can be regenerated.

snapshot_manifest.json preserves the run IDs, recipe hashes, seed values, and learned-artifact hashes
that are not present in the browser's all-metrics CSV format.
