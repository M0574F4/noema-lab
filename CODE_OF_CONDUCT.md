# Code of Conduct

Noema follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project a harassment-free experience for everyone,
regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics,
gender identity and expression, level of experience, education, socio-economic status, nationality,
personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and experiences.
- Give and accept constructive feedback gracefully.
- Focus criticism on ideas, code, evidence, and benchmark protocol details.
- Help keep benchmark discussions reproducible and technically grounded.

## Unacceptable Behavior

Harassment, personal attacks, intimidation, sustained disruption, doxxing, sexualized language or
imagery, and private harassment are not acceptable.

## Enforcement

Project maintainers may remove comments, reject contributions, or limit participation for behavior
that violates this code. Routine moderation requests may be opened through the repository's issue
tracker without including private personal information. For a confidential incident involving a
maintainer, use GitHub Support's private abuse-report channel at
<https://support.github.com/contact/report-abuse>. Security vulnerabilities must use the separate
private reporting route in `SECURITY.md`.
